# SALES-FINANCIAL-DASHBOARD

# Project Overview

This project presents a business dashboard created using the Olist customer dataset. The dashboard analyzes customer distribution across Brazilian states and cities using key customer KPIs and visualizations.

# Key Features

* Total customer records
* Unique customers
* Customer distribution by state
* Top 10 customer cities
* Top 10 customer states
* Geographic customer analysis

# Tools Used

* Power BI / Tableau
* CSV Dataset
* Data Visualization

#Objective

To create an interactive business dashboard that helps stakeholders understand customer distribution and identify regions with higher customer concentration.

# Dataset

Olist Customer Dataset from Kaggle.

# Outcome

The dashboard provides a simple visual overview of customer demographics and geographic distribution to support business decision-making.
